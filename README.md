# Training Log

A mobile web app I built to log my gym sessions. It's a single HTML file saved to my
phone's home screen, so it opens like a normal app.

## What it does
- Logs my three lifting days (Chest & Tri, Back & Bi, Legs) in whatever order the gym allows
- Lets me add or remove exercises on each day as I try new ones
- Records treadmill runs by duration and speed, plus classes I attend
- Keeps weight progression manual, because I'd rather decide when to go up than have the app suggest it

## Why I built it
Existing apps assumed a fixed programme and rotation. I wanted something that matched
how I actually train, so I specified it, built it with Claude and adjusted it after
using it in real sessions.
